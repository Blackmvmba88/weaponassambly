## 2026-08-02 - [Caching static JSON catalog queries and slot enums]
**Learning:** During validation of weapon assembly builds, static properties from JSON-derived catalogs (such as available modules, sockets, and cosmetics) were being traversed and converted into `frozenset` objects on every validation call. In addition, fixed enum options (like `Slot` values) were being rebuilt as sets inline. This created considerable allocation and loop overhead during validation, which is executed repeatedly (and even double-validated inside `resolve_build`). Caching static catalog lookups using `@functools.cache` and extracting enums to module-level static sets avoids these redundant operations completely.
**Action:** When validating structures against loaded configuration files or catalogs, always cache the query functions that retrieve elements or build sets, and move static schema sets/enums into module-level constant sets.
